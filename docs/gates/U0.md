## Definição do gate

ULTRON U0 é o gate mínimo de **especificação viva**. Conclui quando todas as quatro entregas abaixo existem como artefatos versionados, com testes e exemplos.

## Entregas obrigatórias

### 1. Stack e estrutura do repositório
- [x] Linguagem, framework, DB, store, ferramentas definidos e justificados
- [x] Estrutura de diretórios publicada
- [x] `pyproject.toml` com dependências fixadas
- [x] Lint (`ruff`), formatação, type-check (`mypy strict`) configurados

### 2. Schemas iniciais (executáveis)
- [x] `AgentManifest` — Pydantic v2 strict
- [x] `SkillManifest` — Pydantic v2 strict
- [x] `WorkflowManifest` — Pydantic v2 strict
- [x] `PackManifest` — Pydantic v2 strict
- [x] Validação cruzada (deps, conflitos) implementada
- [x] Testes unitários cobrindo casos válidos/inválidos (≥85%)

### 3. Protocolo do consumer (rascunho versionado)
- [x] Interface conceitual `ConsumerAdapter` definida em código (mesmo que stub)
- [x] Versionamento semântico do contrato documentado
- [x] Erros tipados (sem exceções genéricas vazando)

### 4. Modelo de segurança
- [x] Princípio *deny-by-default* codificado em constante
- [x] Lista de permissões válidas (allowlist inicial)
- [x] Validação de permissões solicitadas vs. permissões do consumer
